# UrbanPulse Nexus

UrbanPulse Nexus is a Smart City and Traffic Intelligence Platform designed to support citizens, administrators, and traffic-management teams.

## Features

- Citizen registration and login
- Complaint reporting and tracking
- Admin complaint and user management
- Staff complaint management
- Vijayawada traffic monitoring
- Traffic congestion and incident insights
- Interactive smart city map
- Traffic analytics and reports
- Camera registry architecture
- Local webcam demonstration
- Role-based access control

## Technologies Used

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Leaflet
- React-Leaflet

### Backend

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- JWT authentication
